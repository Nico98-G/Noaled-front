# Gruponoaled.com

Sitio web funcional desarrollado de forma independiente, diseñado para ofrecer una experiencia de usuario fluida y optimizada. El proyecto se encuentra actualmente en producción.

🔗 **Sitio web en producción:** [https://gruponoaled.com](https://gruponoaled.com)

---

## 🚀 Tecnologías utilizadas

Este proyecto fue construido utilizando herramientas y frameworks modernos del ecosistema web:

* **Framework:** [Next.js](https://nextjs.org/) (React)
* **Estilos / UI:** Tailwind, CSS
* **Despliegue:** Vercel

---

## 🛠️ Características principales

* Interfaz de usuario adaptable a distintos dispositivos (Responsive Design).
* Optimización de rendimiento y carga mediante las características de Next.js.
* Arquitectura basada en componentes reutilizables.
